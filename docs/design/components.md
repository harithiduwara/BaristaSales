# Component inventory

REQUIREMENTS.md 10.3. Each component lives in `apps/web/src/components/<Name>/` from Phase 2, with a component test per state. "Proto" names the prototype class in `docs/design/components.css`.

States key: **D** default · **P** hover/pressed · **F** focus-visible · **X** disabled · **E** error · **L** loading · **0** empty.
